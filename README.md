🎬 StreamX — Responsive OTT Platform UI

StreamX is a modern OTT platform UI website built using pure HTML and CSS only (no JavaScript).
The project focuses on responsive design, clean movie cards, hover effects, and a professional streaming layout.

🚀 Features

✅ Fully responsive (Laptop → Tablet → Mobile)
✅ Hero banner with gradient overlay
✅ Hindi trending movies section
✅ New releases section with different movies
✅ Movie cards with hover description effect
✅ Smooth scaling animation on hover
✅ Netflix-style dark UI
✅ Multi-column professional footer
✅ Clean media queries (no frameworks)

🛠️ Tech Stack

HTML5

CSS3 (Flexbox + Grid + Media Queries)

📱 Responsive Breakpoints

Desktop: 1200px and above

Tablet: 768px – 1199px

Mobile: below 768px

🎨 UI Highlights

Hover movie reveal effect

Gradient overlays for readability

Scrollable movie rows on mobile

Clean typography and spacing
